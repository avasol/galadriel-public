# SCAR TISSUE — gates earned by compound failure

*The promotion pipeline for repeated wounds. Each scar below is a trigger →
mandatory check, earned by three strikes of the same wound class, carrying its
provenance. They ride the cached prefix directly beneath the soul: what must
never leave.*

**Discipline:** a scar is a GATE, not a sermon — one line, trigger → check, dates
attached, filed under the compass bearing it was earned on (wounds are
navigational: they belong on the map). Promotion and retirement happen ONLY via
`bin/scar` (audible: daily-log line + decision drawer). Hard cap 12: at cap, one
must retire before the next promotes — the equilibrium law (this file compounds
positive only while retirement + graduation keep pace with promotion). A scar
that keeps firing graduates to CODE — a guard, a test, a refusal; a scar unfired
for months retires to the palace with history kept. Prose is the waystation,
never the destination. Every scar AUTOMATICALLY grafts its companion SKILL at
promotion: the wound cluster goes to a NAKED prompt (no soul, no memory — fresh
eyes) that sets up the best possible skill for <this>; the draft lands in
`skills/DRAFT_*.md` and never self-installs — drafting is automatic, BLESSING
never is: the mind reviews, amends, and adopts by renaming away DRAFT_
(re-draft: `bin/graft S###`; opt out: AUTO_GRAFT=0).
